# Runs

Supported run recipes are organized by workflow:

- `validation/`: validation recipes for individual cohorts.
- `annotations/`: annotation-production recipes.
- `enrichment/`: CHGNet, DXMag, and join enrichment recipes.
- `descriptors/v1/`: frozen Descriptor v1 workflow/artifact area.
- `analysis_v1/`: frozen unified-analysis workflow/artifact area.

Historical experiment material may retain old names elsewhere for provenance.
Frozen scientific artifact filenames are not renamed here.
